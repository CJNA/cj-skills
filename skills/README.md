# Skills Directory

This directory contains skill markdown files that document various skills, competencies, and capabilities.

## Structure

Each skill should be documented in its own markdown file with a descriptive name.

## Adding a New Skill

To add a new skill:
1. Create a new markdown file in this directory
2. Use a descriptive filename (e.g., `python-programming.md`, `project-management.md`)
3. Follow the skill template format (see example below)

## Skill Template

```markdown
# Skill Name

## Description
Brief overview of the skill

## Key Competencies
- Competency 1
- Competency 2
- Competency 3

## Resources
- Resource links
- Learning materials
```
