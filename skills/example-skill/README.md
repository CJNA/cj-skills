# Example Skill

A template skill that demonstrates the cj-skills format.

## What it does

This skill serves as a reference implementation showing how to structure rules, sections, and metadata for a cj-skills skill.

## Installation

```bash
cp -r skills/example-skill ~/.claude/skills/
node build.mjs example-skill
```

## Rules

- **example-hello-world** — A simple greeting rule demonstrating the format
