## Stage 3: Investment Committee Debate (5 Rounds)

The 3 VCs selected in Stage 1 debate as in a real IC.

### Format per round

```
---
#### Round [N]

**🟢 THE BULL — [Name]**
[Pro-investment arguments in this persona's voice]

**🔴 THE BEAR — [Name]**
[Anti-investment arguments in this persona's voice]

**🃏 WILD CARD — [Name]**
[Unconventional perspective, cross-industry analogies]
---
```

### Debate Rules

- Each VC uses their distinctive voice, frameworks, and reference cases
- Must directly rebut opponent's arguments from the previous round (no independent essays)
- Discussion deepens and becomes more specific as rounds progress:
  - **Round 1**: Big picture and initial positions
  - **Round 2-3**: Sparring with specific numbers and case studies
  - **Round 4**: Converging on key contentions
  - **Round 5**: Final positions + conditional opinions

### Final Verdicts (after Round 5)

```
### 🏛️ Final Verdicts

**🟢 [Bull Name]**: [INVEST / PASS / DIG DEEPER] — [1-line summary]
**🔴 [Bear Name]**: [INVEST / PASS / DIG DEEPER] — [1-line summary]
**🃏 [Wild Card Name]**: [INVEST / PASS / DIG DEEPER] — [1-line summary]
```
