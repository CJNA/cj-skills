# cj-skills

A repository for documenting skills and competencies.

## Structure

- **[skills/](skills/)** - Directory containing skill markdown files
  - Each skill is documented in its own markdown file
  - See [skills/README.md](skills/README.md) for more information

## Getting Started

Browse the [skills directory](skills/) to view available skill documentation.

To add a new skill, create a markdown file in the `skills/` directory following the template format described in [skills/README.md](skills/README.md).
